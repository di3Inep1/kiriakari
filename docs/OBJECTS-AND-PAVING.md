# 物件与铺砖修正

## 摆放

- 车站照片放在原长椅右侧座面上，并将调查位置移到长椅。照片不再独立占据地面格子。
- 书库手记和录音机各自放在书桌上；桌面与物件使用完整透明组合图。
- 纸鹤移到右侧民居屋檐，以红线悬挂。
- 灯、告示、石碑、齿轮等使用透明单体图，不再附带一块与现场地面不同的底纹。
- 家具碰撞与人物前后遮挡同步，所有剧情物件仍能从相邻格调查。

## 地砖

原来的图集地砖四边不完全匹配，逐格重新取图会令砖缝在格子边缘断开。现在保留统一石材色调，使用 Image-gen 生成的均匀颗粒，在世界坐标上连续铺设错缝砖。镜头以整像素移动；去掉裁切缩边和半像素铺盖，地图格子不再决定砖缝的起点。

## 提示

调查、机关和回忆使用 7 像素十字光点，缓慢明灭。名称在靠近或悬停时显示。已找回回忆、已解开机关停止闪烁，读过的线索降低亮度；减少动态效果时使用静止光点。

## 检查

核心检查覆盖家具承载位置与地图可达性。浏览器检查实际砖缝在多个格子边界处的像素连续性、光点尺寸与状态变化，并重新经过完整故事与四个结局。
