# 通关攻略（完整剧透）

每一处光点都可以直接点击，澪会自动走近并转向；键盘 E 和手机“调查”只调查人物正前方一格。剧情中的 E / Enter 可显示全文或继续。按 Q / 轻触“引灯”切换回忆，按 B / 顶部“背包”查看和使用道具；所有收集内容会自动保存。

## 主线

1. **雾灯车站**：进入西侧站房，在矮柜取走熄灭的引灯。向莲借黄铜钥匙，打开站台最东端的维修箱，获得防潮火柴。打开背包，选火柴并使用：屋外尝试会被风吹灭，火柴保留；回站房再使用即可自行点亮。也可直接在室内点灯。经历屋外失败后再点亮，会得到隐藏成就“学会护火”。莲只提供线索。点灯后可再与莲交谈、答应带话；暂时拒绝仍能补做。首次成功点灯播放 CG，可在手记“回忆”页回看。
2. 按 Q 进入回忆，调查「褪色的时刻表」，得到七月十六日的线索。长椅合照和屋檐纸鹤仅在回忆中显现；调查合照会播放姐妹的回忆 CG。
3. 调查检票闸门，从左到右设为 **0、7、1、6**，确认。
4. 前往灯见街，和凪婆婆交谈。修灯需要：在回忆中调查东侧民居檐边针线篮取得红线，调查主街南边石井取得清水，进入西侧制灯铺，在糨糊台用清水调米糊。带好材料找婆婆，或在铺内工作台修灯，会消耗红线和米糊，并获得归舟歌。修灯可以稍后补做，不会挡住神社主线。
5. 前往月见神社，在回忆中调查「被雨洗去的绘马」。
6. 调查四方灯阵，按 **月 → 山 → 川 → 舟** 点击四盏灯并确认，取得四灯印钥。
7. 按 M 前往旧校书库，在回忆中调查「值日生的手记」。
8. 调查祭典记录柜，点击两张记录交换位置；从左到右排列为 **寄信 → 借灯 → 开闸 → 敲钟**，确认。
9. 前往十三刻钟楼，在回忆中调查「齿轮旁的刻痕」。
10. 与回忆中的栞交谈，听完她真正的心愿。
11. 调查停转的钟芯。初始三个轮都是十二点；**转上轮一次、下轮两次**，确认启动。目标是 **九点、三点、六点**。
12. 前往渡灯桥，和栞交谈，选择结局。还没准备好时，可以关闭选择界面继续探索。

## 开场支线与室内

- 站房寄物架上的旧包裹可以带给凪婆婆。初次交谈后再次交谈即可交付，得到送灯路线图；不会消耗修灯材料。
- 站房的值班簿和制灯铺的旧样本分别记录找火种、修纸灯的方法，读过后会进入手记。
- 从站房和制灯铺的南门离开，会回到对应建筑门前，不会把人物送回区域入口。
- 候车室采用连续木地板；制灯铺工作台下是两张完整榻榻米，不是按地图格重复的小垫子。

## 真结局的三份约定

- 在车站答应莲：替他告诉栞「我们已经不害怕天亮了」。之前没答应，可再次交谈补做。
- 在灯见街帮凪婆婆修好纸灯。之前只追问去向，可再次交谈补做。
- 在钟楼的回忆中，与栞交谈并听到最后。

加上四段回忆和已经完成的钟楼，即可选择 **「叫出她的名字，让所有灯一起渡河」**。其他三种结局没有收集门槛。

## 不必重打

看完任何结局，点击「回到最后的选择」即可继续探索或选择别的结局。回忆、约定和谜题进度全部保留，结局之书累积记录。手动存档也可以在设置里保存和读取。
