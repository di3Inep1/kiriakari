# 通关攻略（完整剧透）

每一处光点都可以直接点击，澪会自动走近。剧情中的 E / Enter 可显示全文或继续。按 Q 切换回忆；所有收集内容会自动保存。

## 主线

1. **雾灯车站**：和莲交谈，取得引灯。推荐答应替他把话带给姐姐。
2. 按 Q 进入回忆，调查「褪色的时刻表」，得到七月十六日的线索。
3. 调查检票闸门，从左到右设为 **0、7、1、6**，确认。
4. 按 M 前往灯见街，和凪婆婆交谈。推荐选择「我来帮您」，修好纸灯。
5. 前往月见神社，在回忆中调查「被雨洗去的绘马」。
6. 调查四方灯阵，按 **月 → 山 → 川 → 舟** 点击四盏灯并确认，取得四灯印钥。
7. 按 M 前往旧校书库，在回忆中调查「值日生的手记」。
8. 调查祭典记录柜，点击两张记录交换位置；从左到右排列为 **寄信 → 借灯 → 开闸 → 敲钟**，确认。
9. 前往十三刻钟楼，在回忆中调查「齿轮旁的刻痕」。
10. 与回忆中的栞交谈，听完她真正的心愿。
11. 调查停转的钟芯。初始三个轮都是十二点；**转上轮一次、下轮两次**，确认启动。目标是 **九点、三点、六点**。
12. 前往渡灯桥，和栞交谈，选择结局。还没准备好时，可以关闭选择界面继续探索。

## 真结局的三份约定

- 在车站答应莲：替他告诉栞「我们已经不害怕天亮了」。之前没答应，可再次交谈补做。
- 在灯见街帮凪婆婆修好纸灯。之前只追问去向，可再次交谈补做。
- 在钟楼的回忆中，与栞交谈并听到最后。

加上四段回忆和已经完成的钟楼，即可选择 **「叫出她的名字，让所有灯一起渡河」**。其他三种结局没有收集门槛。

## 不必重打

看完任何结局，点击「回到最后的选择」即可继续探索或选择别的结局。回忆、约定和谜题进度全部保留，结局之书累积记录。手动存档也可以在设置里保存和读取。
