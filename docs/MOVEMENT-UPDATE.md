# 移动与行走动画修正

## 本轮修正

- 转向输入不再清空走到一半的步进状态，避免人物回弹到上一格。
- 每帧剩余移动时间传递给下一步，连续跨格时不会插入短暂停顿或站姿。
- 多方向同时按下时，以最近按下的方向为准；松开该方向后继续响应仍按住的方向。
- 点击寻路和键盘接管均从当前一步的终点继续规划，保持位置连续。
- 松开移动键后完成当前一步，再保存停留位置，减少移动期间同步存档带来的阻塞。

## 行走图集

`assets/mio-walk-v2.png` 由内置 image_gen 生成并修正，采用 3 列 × 4 行，行依次朝南、西、东、北，列依次为迈左步、站姿、迈右步。初稿 mio-walk.png 保留作制作记录；正式版本补正了南北朝向的相反迈步。

使用真实帧切换替代角色整体晃动。连续行走时步态相位保持连续，停下显示中间站姿。其他固定 NPC 沿用原始静止图集。

## 验证

- 8 项移动规则检查：快速转向、同时按键优先级、逐格时间衔接、30/60/144 Hz 一致性、停止落格、步态帧、墙体碰撞、出入口中断。
- 浏览器实测右移途中按上、松上继续右移，确认坐标不回退、跨格不出现空闲帧，且三个动画帧均实际播放。
- 浏览器重新经过点击寻路、所有主线机关、四种结局、存档与手机布局。
- 最终图集额外以 `node tests/browser.cjs --movement-only` 检查四个方向和站姿恢复。
