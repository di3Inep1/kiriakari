# 车站与民居布局重排

最新的站房与制灯铺生活化陈设、室内外比例和家具朝向调整，见 [室内布局记录](INTERIOR-LAYOUT.md)。

## 建筑轮廓收口

车站、民居与神社的屋顶改为独立于墙体的轮廓：瓦面两侧斜向展开，檐口向左右各挑出 0.4 格，并补上侧边包边、檐口厚度、墙角立柱与侧面阴影。屋顶表面与檐口继续使用原有 image_gen 图集 `assets/tileset.png`，没有引入不同色调的新贴图。地图缩略图与实景使用同一套绘制，建筑碰撞和纸鹤的依附坐标保持一致。

## 车站

车站从大块空地与独立门板改为连续的功能分区：北侧终端轨道与止冲挡、站台安全线、西侧站房、候车长椅、时刻表、南侧检票栏杆和出站步道。长椅避开站房门口，出口与检票口处于同一条路线。

检票机关使用关闭和打开两种实际闸门图。关闭时栏杆线不能绕过；解开日期机关后，中央通道开放。后续可通过该通道前往灯见街。

## 民居与纸鹤

前排民居调整为三排屋顶、两排屋身，增加门前台阶与通向主街的步道。

移除旧的「独立屋檐加纸鹤」组合图。正式纸鹤为单独透明图，挂线从右侧民居真实屋檐垂下，鸟身位于建筑前墙内、门旁上方。显示位置、挂线和调查位置均从父建筑计算，避免房子调整后物件仍留在草地上。

## 进度兼容

增加地图布局版本。旧版车站、街道存档重新加载时，人物回到该场景安全入口，线索、回忆、约定、机关与结局记录均保留。

## 前后遮挡修正

建筑由地面底图移至独立透明层，与人物、路障、花丛统一按脚底或根部排序。建筑以墙脚为基线，挂在墙上的纸鹤紧随父建筑，后方铁道止冲挡与植物会被屋顶遮住。深度精度提高到每格 100 级，避免小数位置的花丛和人物提前交换前后；落叶保持地面层，场景按钮和文字始终置顶。地图缩略图沿用相同排序。回忆模式的建筑保留原有色调处理。
